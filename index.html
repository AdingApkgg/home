Asuna 的个人主页：写代码、搭服务，偶尔写点东西。下面是博客、自建小工具、开源项目、看番入口和朋友站的索引。

  • 博客 — 主要写东西的地方，建站、运维、代码和杂记都在这里。
  • 关于 — 我是谁、这台站在做什么，以及怎么找到我。
  • 音乐 — 最近在听的歌单，跟着一起放也行。
  • 个人空间 — 个人空间 i.saop.cc 的全栈源码：文章、相册、音乐、Live2D 看板娘，Hono + React Router 8。
  • WVN — 线上视觉小说的应用源码：多引擎统一播放器、Passkey 账号、云存档与分享。
  • adx-dl — AstroDX 谱面存档站与远程目录构建器，抓取、校验、出站串成一条链。
  • thp — 东方 TH14 的 Web 移植工作区，逐帧对照原版录像基线，进度和证据都写在 docs 里。
  • ACGN Flow — 流媒体投稿与播放平台的源码：视频直链、弹幕字幕、合集与后台。
  • Wine Workspace — 在网页里管 Wine：Bottle、程序、依赖和日志，Linux 端还带 noVNC 桌面。
  • live2d-loader — 发到 npm 的 Live2D 加载器，Cubism 2 与 4/5 同一套 API，可直接当 Web Component 用。
  • bsz 源码 — 不蒜子计数器的自托管重写，Rust 单二进制、零外部依赖。
  • vns — 早期视觉小说站的 Hugo 源码，索引和分类都还留着。
  • GitHub 全部仓库 — 公开的仓库都在这里，边角料和实验也在。
  • 不蒜子 — 自建的访问计数接口，这个页面底下那两个数字就是它记的。
  • 随图 — 随机图片接口，按分类返回一张图，用来给页面配背景。
  • 旮旯聚搜 — 跨站聚合搜索，一次查完多个视觉小说资源站。
  • 动漫聚搜 — 番剧与资源的聚合检索入口。
  • ACGN Flow — 按季度整理的番剧放送表，追番时看进度用。
  • B站解析 — 丢一个视频链接进去，取出直链，方便离线看。
  • ADX 谱面 — 音游 ADX 的谱面收集与下载，按曲目整理。
  • 图吧工具 — 装机时会用到的一堆在线小工具，打包在一个页面里。
  • 原神启动 — 点一下就跳转到原神启动页，省得自己找。
